# UK Dream - Playwright Automation Project

## Project Overview
Automation testing project for the UK Dream web application.

Application URL: https://app.myukdream.com/

## Technology Stack
- Playwright
- TypeScript
- Visual Studio Code
- Page Object Model (POM)

## Test Cases
- Contact Us page testing
- Example Playwright tests

## Installation
npm install

## Run Tests
npx playwright test

## View Report
npx playwright show-report
